# Prompt para Stitch — Dashboard administrativo FORJEZ

Create a high-fidelity responsive admin dashboard for FORJEZ Consulting to manage leads, client diagnostics, proposals and consulting projects.

Brand personality:
- Executive.
- Operational.
- Strategic.
- Trustworthy.
- Clean and data-driven.

Visual direction:
- Use deep petroleum blue, strategic green and sober gold accent.
- Light neutral background.
- Sidebar navigation.
- Clear KPI cards.
- Tables with filters.
- Pipeline visualization.
- Professional consulting feel, not a generic SaaS template.

Dashboard sections:

1. Sidebar:
   - Inicio
   - Leads
   - Diagnósticos
   - Clientes
   - Propuestas
   - Proyectos
   - Reportes
   - Configuración

2. Topbar:
   - Search
   - Notifications
   - User profile

3. KPI cards:
   - Leads nuevos
   - Diagnósticos activos
   - Propuestas enviadas
   - Clientes en implementación
   - Tareas vencidas

4. Lead pipeline:
   - Nuevo
   - Contactado
   - En diagnóstico
   - Propuesta enviada
   - Ganado
   - Perdido

5. Main table:
   Columns:
   - Empresa
   - Contacto
   - Servicio de interés
   - Estado
   - Última interacción
   - Responsable
   - Acción

6. Right panel:
   - Próximas tareas
   - Diagnósticos próximos a vencer
   - Alertas operativas

UX requirements:
- Include empty state.
- Include loading state.
- Include filters by state and service.
- Include mobile adaptation.
- Use Spanish UI copy.
- Do not include real company/client data. Use fake placeholder data clearly generic.

Implementation target:
Design should be easy to convert into Next.js + TypeScript + Tailwind components.
