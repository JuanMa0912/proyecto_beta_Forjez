# Documentacion

Indice de documentos fuente del proyecto.

- `brand_context.md`: contexto de marca, tono y posicionamiento.
- `product_scope.md`: alcance base del producto.
- `functional_requirements.md`: requerimientos funcionales iniciales.
- `security_requirements.md`: reglas obligatorias de seguridad.
- `branching_strategy.md`: ramas, commits y pull requests.
- `definition_of_done.md`: criterios minimos de entrega.
- `repository_structure.md`: mapa de carpetas y responsabilidades.
