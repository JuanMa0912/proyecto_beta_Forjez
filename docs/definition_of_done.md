# Definition of Done

Una tarea se considera terminada cuando:

- Cumple los criterios de aceptación.
- Respeta la identidad de FORJEZ.
- Tiene diseño responsive.
- Tiene estados de carga, vacío y error cuando aplica.
- Valida entradas.
- No expone secretos.
- No rompe TypeScript.
- No rompe lint.
- Tiene pruebas o verificación manual documentada.
- Está documentada si introduce decisiones relevantes.
- Incluye pendientes explícitos si hay información faltante.
